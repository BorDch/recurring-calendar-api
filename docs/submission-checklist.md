## Исправления и ограничения

Локальный POST на маршрут чтения с действующей CSRF-проверкой возвращал `403` вместо заявленного `405`. Для локального профиля убрано CSRF-препятствие перед проверкой метода; добавлен точечный регрессионный тест для двух маршрутов чтения. Для production-тестов предварительно нужен `collectstatic`, поскольку профиль использует manifest-хранилище статики. Исходный скриншот не показывал нижнюю неделю ноября; заменён полным кадром. Схема README сокращена, альтернативные базы и связь сущностей пояснены.

На целевом хостинге ещё нужно проверить TLS, DNS, секреты, reverse proxy, `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS`, сборку статики, мониторинг, резервное копирование и восстановление. Удалённый CI для этих незакоммиченных изменений не запускался. Коммит, push и merge оставлены для последующего ревью.
